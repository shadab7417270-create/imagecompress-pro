# ImageCompress Pro

Open `index.html` in a modern browser. No build step is required.

Features:
- JPG/JPEG/PNG/WebP upload
- Drag and drop
- Batch compression
- Quality presets
- Browser-side processing
- Individual downloads
- download for all results
- Responsive design
- FAQ and privacy sections

Note: PNG files are encoded to WebP during compression to achieve stronger size reduction.
